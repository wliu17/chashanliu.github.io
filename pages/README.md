# Legal English · Unit 1 · Interactive Study Guide

Single-page study guide (Text A and Text B) with sentence-by-sentence audio, key-term pop-ups with Chinese equivalents, and a glossary.

## Publish on GitHub Pages
1. Create a new repository on github.com (for example `legal-english-unit1`).
2. Upload `index.html` (and `.nojekyll`, `README.md`) to the repository root.
3. Settings → Pages → Build and deployment → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. After a minute the page is live at `https://<your-username>.github.io/legal-english-unit1/`.

## Audio
Audio uses the browser's built-in speech voices (Web Speech API), so there are no audio files to host. Best in Chrome, Edge or Safari; voice quality depends on the device. Chinese terms need a Chinese voice installed on the device.

## Copyright note
Text B (Willis, 1926) is included in full. Text A comes from a 2016 journal article still in copyright, so it is not reproduced: each section shows the handout paragraph locator and an original plain-English version. Students can paste the handout paragraph into the page to hear it read; pasted text stays in their browser.
