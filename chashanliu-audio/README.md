# 音频专区 · 使用说明

1. 把 `pages/audio.md` 放进站点的 `pages/` 目录
2. 把 `assets/audio/` 整个文件夹放进站点根目录的 `assets/` 下
3. 在 `index.md` 里新增一张卡片，`href` 指向 `pages/audio.md`
4. 每段音频的标题在 `pages/audio.md` 里搜索「请改为标题」逐个替换
5. `git add . && git commit -m "add audio page" && git push`

注意：音频总计约 60 MB，单文件均小于 GitHub 的 100 MB 上限。
